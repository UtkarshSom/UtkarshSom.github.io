# Utkarsh Som — Portfolio

Static site (HTML, CSS and vanilla JS). No build step, no dependencies.

## Deploy to GitHub Pages

1. Create a repo (for a root URL name it `<your-username>.github.io`).
2. Put `index.html`, `style.css`, `script.js` and `.nojekyll` at the repo root, then push.
3. Repo **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
4. Live at `https://<your-username>.github.io/` within a minute or two.

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
